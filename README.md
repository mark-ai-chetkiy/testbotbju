# 🥗 БЖУ и Тамагочи — Mini App и Telegram-бот для подсчёта калорий

**Основной продукт сейчас — статический Mini App без сервера:**
https://mark-ai-chetkiy.github.io/testbotbju/

Открывается кнопкой «Открыть Тамагочи» в меню [@GymTamagotchi_bot](https://t.me/GymTamagotchi_bot)
или ссылкой `https://t.me/GymTamagotchi_bot?startapp=channel`.
Раздаётся через GitHub Pages из папки `docs/`, данные хранятся в `localStorage` устройства.
Постоянно работающий сервер для самого приложения не нужен.

Mini App умеет: поиск по 344 продуктам и расчёт порции, **распознавание еды по фото через Gemini**,
35 рецептов, личная норма, дневник с историей за 7 дней, питомец, который растёт за ведение дневника,
и вкладка «Зал» с клубным челленджем: чекины в зал, серия дней, XP питомцу
и кнопка «Поделиться результатом» для тренера.

Фото-ИИ работает через endpoint `POST /api/recognize` на уже задеплоенном боте: ключ Gemini
остаётся в переменных окружения сервера и **не попадает в JavaScript**. Приложение при открытии
заранее «разогревает» сервис; первый запрос после долгого простоя всё же может занять до ~40 секунд.
Приложение при этом остаётся статическим и работает, даже если сервис ИИ временно недоступен.

Ниже описан Python-бот на Render — он используется как точка входа и как сервер для фото-ИИ.

## Что умеет старый бот

| Функция | Как пользоваться |
|---|---|
| 👤 Расчёт нормы калорий и БЖУ | Кнопка «👤 Профиль» или `/profile` — пол, возраст, рост, вес, активность, цель. Формула Миффлина–Сан Жеора |
| 🔍 Подсчёт продукта | Написать «гречка 150» или `/food гречка 150` |
| 📷 Распознавание по фото | Кнопка «📷 Фото еды» или `/photo` — пришли фото блюда |
| 📖 Рецепты с БЖУ | Кнопка «📖 Рецепты» или `/recipes` — 35 блюд |
| 📊 Дневник за день | Кнопка «📊 Дневник» или `/today` — съеденное, прогресс-бары и остаток до нормы |
| ⚙️ Сброс дня | Кнопка «⚙️ Сброс» или `/reset` |

База: **344 продукта** (`data/products.json`) и **35 рецептов** (`data/recipes.json`).


## Локальный запуск

Нужен **Python 3.10+** (проверено на 3.13).

```bash
cd ~/bju-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env      # затем впиши токены в .env
python bot.py
```

Или одной командой: `./run.sh` (сам создаст окружение и поставит зависимости).

Чтобы бот работал в фоне и пережил закрытие терминала:

```bash
nohup ./.venv/bin/python bot.py > bot.log 2>&1 &
tail -f bot.log            # смотреть логи
pkill -f bot.py            # остановить
```

Где взять ключи:
1. **BOT_TOKEN** — напиши [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен.
2. **GEMINI_API_KEY** — [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
   → «Create API key». Бесплатного лимита хватает для старта.

> ⚠️ **macOS + python.org:** один раз запусти `/Applications/Python 3.13/Install Certificates.command`,
> иначе будет ошибка `CERTIFICATE_VERIFY_FAILED` при обращении к Telegram API.

### Украсить профиль бота

```bash
python setup_bot.py       # имя, описания и меню из 8 команд
```

### Тесты без сети

```bash
python tests/smoke_handlers.py   # прогон всех сценариев на виртуальных апдейтах
```

## Деплой на Render.com (бесплатно, 24/7)

💡 **Пошаговая инструкция со скриншотами текстом — в `DEPLOY.md`.** Коротко:

1. Создай пустой репозиторий `bju-bot` на GitHub (без README).
2. Подключи проект и запушь: `git push -u origin main` (пароль = токен GitHub с правами `repo`).
3. На render.com → **New → Blueprint** → выбери репозиторий → в Environment впиши `BOT_TOKEN` и `GEMINI_API_KEY`.
4. Проверка: `https://bju-bot.onrender.com/health` → `OK`.
5. Чтобы бот не засыпал: UptimeRobot-монитор на `/health` каждые 5 минут.

## Как пополнять базу

- **Продукт** — добавь строку в `data/products.json`:
  `{"n":"название","p":белки,"f":жиры,"c":углеводы,"k":калории}` (на 100 г).
- **Рецепт** — в `data/recipes.json`:
  `{"n":"название","s":порций,"p":...,"f":...,"c":...,"k":...,"d":"краткий рецепт"}`
  (значения на 1 порцию).

После правок файлов на Render сделай Manual Deploy.
