# 🥗 БЖУ-бот — Telegram-бот для подсчёта калорий и БЖУ

Бесплатный Telegram-бот: считает личную норму калорий/БЖУ, калорийность продуктов
и блюд, распознаёт еду по фото (Google Gemini) и ведёт дневник питания.

## Что умеет

| Функция | Как пользоваться |
|---|---|
| 👤 Расчёт нормы калорий и БЖУ | Кнопка «👤 Профиль» или `/profile` — пол, возраст, рост, вес, активность, цель. Формула Миффлина–Сан Жеора |
| 🔍 Подсчёт продукта | Написать «гречка 150» или `/food гречка 150` |
| 📷 Распознавание по фото | Кнопка «📷 Фото еды» или `/photo` — пришли фото блюда |
| 📖 Рецепты с БЖУ | Кнопка «📖 Рецепты» или `/recipes` — 35 блюд |
| 📊 Дневник за день | Кнопка «📊 Дневник» или `/today` — съеденное, прогресс-бары и остаток до нормы |
| ⚙️ Сброс дня | Кнопка «⚙️ Сброс» или `/reset` |

База: **344 продукта** (`data/products.json`) и **35 рецептов** (`data/recipes.json`).

## Структура проекта

```
bju-bot/
├── bot.py                # точка входа: polling + health-check для Render

├── nutrition.py          # расчёты БЖУ, поиск по базе
├── render.py             # визуал: карточки, прогресс-бары (HTML)
├── gemini.py             # распознавание еды по фото
├── ui.py                 # меню и роутинг кнопок/команд
├── setup_bot.py          # разовая настройка профиля бота (имя, описание, команды)
├── handlers/             # сценарии бота (start, profile, food, photo, recipes, diary)

├── Dockerfile, render.yaml

```

## Локальный запуск

Нужен **Python 3.10+** (проверено на 3.13).

```bash
cd ~/bju-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env      # затем впиши токены в .env
python bot.py
```

Или одной командой: `./run.sh` (сам создаст окружение и поставит зависимости).

Чтобы бот работал в фоне и пережил закрытие терминала:

```bash
nohup ./.venv/bin/python bot.py > bot.log 2>&1 &
tail -f bot.log            # смотреть логи
pkill -f bot.py            # остановить
```

Где взять ключи:
1. **BOT_TOKEN** — напиши [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен.
2. **GEMINI_API_KEY** — [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
   → «Create API key». Бесплатного лимита хватает для старта.

> ⚠️ **macOS + python.org:** один раз запусти `/Applications/Python 3.13/Install Certificates.command`,
> иначе будет ошибка `CERTIFICATE_VERIFY_FAILED` при обращении к Telegram API.

### Украсить профиль бота

```bash
python setup_bot.py       # имя, описания и меню из 8 команд
```

### Тесты без сети

```bash
python tests/smoke_handlers.py   # прогон всех сценариев на виртуальных апдейтах
```

## Деплой на Render.com (бесплатно, 24/7)

1. Залей проект в репозиторий GitHub.
2. На [render.com](https://render.com) → **New → Blueprint** → выбери репозиторий
   (Render сам прочитает `render.yaml`).
3. Впиши `BOT_TOKEN` и `GEMINI_API_KEY` в разделе Environment.
4. Deploy.

⚠️ На бесплатном тарифе Render усыпляет сервис после 15 минут без HTTP-запросов.
Чтобы бот не засыпал, заведи бесплатный монитор на [uptimerobot.com](https://uptimerobot.com):
тип **HTTP(s)**, адрес `https://ТВОЙ-СЕРВИС.onrender.com/health`, интервал 5 минут.
Бот отдаёт `OK` по `/` и `/health`.

## Как пополнять базу

- **Продукт** — добавь строку в `data/products.json`:
  `{"n":"название","p":белки,"f":жиры,"c":углеводы,"k":калории}` (на 100 г).
- **Рецепт** — в `data/recipes.json`:
  `{"n":"название","s":порций,"p":...,"f":...,"c":...,"k":...,"d":"краткий рецепт"}`
  (значения на 1 порцию).

После правок файлов на Render сделай Manual Deploy.
