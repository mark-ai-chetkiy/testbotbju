# 🚀 Деплой на Render.com (бесплатно, 24/7)

Пошаговая инструкция. Начинай с раздела **1** и иди по порядку.
Всё, что написано в `~/bju-bot/DEPLOY.md` — ты уже читаешь.

---

## 1. GitHub-аккаунт и репозиторий (~5 минут, в браузере)

1. Открой **https://github.com/join** → создай аккаунт (если нет).
2. Зайди на **https://github.com/new** → заполни:
   - **Repository name:** `bju-bot`
   - **Visibility:** `Private` или `Public` — не важно. `Private` надёжнее.
   - **НЕ** отмечай «Add a README», «.gitignore», «license» — репозиторий должен быть **пустым**.
3. Нажми **Create repository**.
4. Создай токен для загрузки кода:
   - Открой **https://github.com/settings/tokens** → **Generate new token** → **classic**.
   - Name: `push-bju-bot`, срок: например 90 дней.
   - Поставь галочку **repo** (первая, верхняя).
   - Внизу **Generate token** → **скопируй токен** (показывается один раз!).
5. Сообщи мне **свой юзернейм на GitHub** — я подключу репозиторий и дам последнюю команду.

> Токен GitHub — это почти пароль. Не вставляй его в этот чат: он нужен только
> в терминале, когда git спросит пароль.

## 2. Загрузка кода (1 команда в терминале)

```bash
cd ~/bju-bot
git push -u origin main
```

Git спросит:
- **Username:** твой GitHub-юзернейм
- **Password:** вставь скопированный токен (символы не показываются — это нормально)

## 3. Деплой на Render (~5 минут, в браузере)

1. Открой **https://render.com** → **Sign up** → регистрируйся через **GitHub** (одна кнопка).
2. На главной → **New** → **Blueprint** (не Web Service!).
3. Выбери репозиторий `bju-bot` → жми **Apply**.
4. Render прочитает `render.yaml` сам. Откроется страница настройки:
   - В зелёной панели справа открой **Environment** каждого сервиса (он один — `bju-bot`):
     - **BOT_TOKEN** — токен из `~/bju-bot/.env`
     - **GEMINI_API_KEY** — ключ из `~/bju-bot/.env`
   - Остальные значения уже стоят.
5. Нажми **Apply / Deploy**.
6. Через 3–5 минут зайди на `https://bju-bot.onrender.com/health` — должен ответить `OK`.
7. Проверь бота в Telegram: напиши `/start` — если отвечает, всё работает.

## 4. Чтобы бот не засыпал (важно!)

Бесплатный тариф Render усыпляет сервис после ~15 минут без HTTP-запросов.
Бот «просыпается» сам по первому обращению, но чтобы он всегда был активен:

1. Зарегистрируйся на **https://uptimerobot.com** (бесплатно).
2. **Add New Monitor**:
   - Monitor Type: **HTTP(s)**
   - URL: `https://bju-bot.onrender.com/health`
   - Interval: **5 minutes**
   - Создай.
3. Готово: монитор пингует бота каждые 5 минут, и тот не засыпает.

> Замечание: на бесплатном тарифе диски Render очищаются при каждом деплое
> (данные дневников в SQLite временные). Для постоянного хранения позже добавим
> бесплатную базу Postgres на Render.

## 5. Как обновлять бота после правок

```bash
cd ~/bju-bot
git add -A
git commit -m "описание изменения"
git push
```

Render пересоберёт и задеплоит автоматически (по кнопке **Manual Deploy** в панели,
если автодеплой отключён).
